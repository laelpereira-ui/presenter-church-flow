# Presenter Church Flow

Site oficial e downloads do **Presenter Church Flow**, software de projeção gratuito para igrejas e eventos.

- Site: https://presenterchurchflow.vercel.app
- Instaladores: separador **Releases** deste repositório (Windows `.exe`, macOS `.dmg`).

O programa é gratuito, sem anúncios e completo. O código do programa não está neste repositório.
© 2026 Lael Pereira.

## Como publicar uma versão nova
1. Em **Releases › Draft a new release**, crie a etiqueta `vX.Y.Z` (ex.: `v0.1.1`).
2. Escreva as novidades (uma por linha, com `-` no início) e anexe os instaladores
   (`Presenter-Church-Flow-Setup-X.Y.Z.exe`, `…-mac-arm64.dmg`, `…-mac-x64.dmg`).
3. Publique. O site mostra a versão nova sozinho; as anteriores passam para "Versões anteriores".
