# Bíblias grátis do Presenter Flow

Versões da Bíblia em **domínio público** (livres de direitos de autor, sem obrigação de dar crédito), prontas para instalar no Presenter Flow com um clique (painel Bíblia › **📖 Bíblias grátis**).

- Formato: **Zefania XML**, comprimido com gzip (`.xml.gz`). Só os 66 livros, sem notas de rodapé.
- `catalogo.json`: lista lida pelo programa (o campo `sha256` é do XML descomprimido; o programa confere-o antes de instalar).
- Fontes: a maioria vem do repositório [open-bibles](https://github.com/seven1m/open-bibles) (versões marcadas «Public Domain»); a Almeida 1911 é o texto original de 1911.
- Versões com direitos de autor (NVI, ARA, NAA, NVT…) **não** estão aqui: cada igreja importa o arquivo XML que pode usar.
